## New Opportunities and Terms for iOS Developers in Brazil

Following an agreement with Brazil's competition authority (CADE), Apple **updated the Apple Developer Program License Agreement**. The change centers on **allowing alternative app marketplaces, alternative payment systems, and out-of-app offers** for iOS apps in Brazil. The policy applies from iOS 26.5 and gives developers more options for distributing and monetizing apps in Brazil, subject to the Core Technology Commission. All developers must review and accept the updated terms (Attachment 12).

## Google Announces Agent Collaboration Protocol (A2A) Milestone and Open Standards

Marking **one year of the Agent-to-Agent (A2A) protocol**, which enables secure collaboration between autonomous AI agents, Google highlighted how the framework lets agents delegate complex workflows, avoid context pollution, and keep data private while designing modular applications, without the constraints of traditional APIs. It showed A2A's practicality through "FoldRun," an agent interface for the life sciences.

Google also announced the **Agentic Resource Discovery specification, an open standard for AI agents to find and verify the tools, skills, and other agents they need** across the web. It should become an important foundation for interoperability and growth in the agent ecosystem.

In addition, it introduced **three architectural patterns that combine A2UI (Agent-to-User Interface) with MCP (Model Context Protocol) apps to get the benefits of both declarative UI and custom agent UI**. Developers can build hybrid frameworks that serve native-like UI directly from an MCP server, safely embed complex stateful iframe apps in declarative views, and inject generative UI components into existing systems.

## AI Agents from Tool to Colleague: Real Development and Service Cases

Software engineer **Martin Fowler** shared his experience building an LLM-based system for pharmaceutical research and stressed the **importance of designing stable, trustworthy agentic AI systems**. Through building a system that can query decades of research buried in PDF reports, it offers deep insight into what it takes to use LLMs in real environments.

In Korea, the **Naver and Toss tech blogs** published real applications of AI and development experience.

**Naver D2** shared sessions from NAVER ENGINEERING DAY 2026:
*   **"Change the Spec and the Prompt Follows: An Automated Pipeline for Answer Generation Models"**: For a shopping agent answer model whose input spec changes often, the team designed a pipeline where entering the changed spec lets an agent run defect detection, prompt optimization, and SFT training data generation in a closed loop. It offers practical productivity gains for AI service planners and engineers.
*   **"From Tool to Colleague: A Framework for Self-Growing AI Agents"**: Going beyond AI that resets every session, it presents the design principles (3 loops + a constitution + five-layer memory) and implementation of "GNOSIS," an agent framework that accumulates experience and grows on its own.
*   **"Replacing SaaS: Building an Ad SDK Error Monitoring System with AI"**: To overcome the structural limits of integrating general-purpose error monitoring tools in a third-party SDK environment, the team used AI agents to build its own JavaScript error monitoring system, showing how agents can raise productivity and help build internal tools beyond the limits of external SaaS.

The **Toss Tech blog** also covered practical uses of AI:
*   **"How AI Changed the Order of Product Design"**: While building a customer service chatbot, the team created a good user experience first and used AI to work backward to what was needed, showing AI's effect on the product design process.
*   **"Why a Designer Built an App Instead of a Mockup"**: A designer used AI to build the design in their head as a real app instead of a mockup, showing how AI can change design and prototyping workflows.
