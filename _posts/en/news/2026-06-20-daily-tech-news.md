## Today's Developer News: Evolving AI Agents and a Changing App Ecosystem (June 20, 2026)

### The AI Agent Ecosystem: Protocols, Specs, and Self-Growth

**1. Google Announces Agent Collaboration Protocol Milestone and a Resource Discovery Spec**

Marking the first anniversary of the A2A (Agent-to-Agent) protocol for secure collaboration between AI agents, Google highlighted how the framework lets autonomous agents delegate complex workflows to specialized agents and work together beyond the limits of traditional APIs. It prevents context pollution, protects data privacy, and simplifies application design through modularity.

Google also announced "Agentic Resource Discovery," an open spec for finding and verifying tools, skills, and agents across the web, which should greatly improve discoverability and interoperability in the agent ecosystem.

It further introduced three architectural patterns for integrating A2UI (Agent-to-User Interface) with MCP (Model Context Protocol) apps, combining the strengths of declarative UI and custom agent UI. Developers can serve native-like UI directly from an MCP server, safely embed complex stateful iframe apps inside declarative views, or inject generative UI components into legacy systems.

[Source URL](https://developers.googleblog.com/announcing-the-agentic-resource-discovery-specification/) (Google Developers Blog)
[Source URL](https://developers.googleblog.com/a2ui-and-mcp-apps/) (Google Developers Blog)

**2. Naver D2 Shares AI Agent Automation and a Self-Growing Agent Framework**

Naver D2 shared its experience developing a shopping agent answer model, presenting a pipeline in which, where the input spec changes often, an agent automates defect detection, prompt optimization, and SFT (supervised fine-tuning) training data generation in a closed loop. It offers important insight into making AI service development more efficient.

Naver also presented the design principles and implementation of "GNOSIS," an agent framework that accumulates experience and grows on its own instead of resetting every session. GNOSIS lays out a vision of AI agents evolving "from tool to colleague," enabling continuous learning through a 3-loop architecture, a constitution, and a five-layer memory system.

### Apple Developer Program and iOS Ecosystem Changes: New Opportunities in Brazil

**3. Major Changes Coming to Brazil's iOS App Market**

Following an agreement with CADE (Conselho Administrativo de Defesa Econômica), Brazil's competition regulator, Apple announced major changes for iOS developers in Brazil. Starting with iOS 26.5, developers can distribute apps through alternative app marketplaces or operate their own. They can also use payment processors other than Apple In-App Purchase for digital goods and services.

The changes are set out in an update to Attachment 12 of the Apple Developer Program License Agreement, including the "Core Technology Commission." They create new business models and competition in the Brazilian market and should give developers more flexibility and monetization options. All affected developers must review and accept the updated terms.
[Source URL](https://developer.apple.com/news/?id=umq9wxmm) (Apple Developer News)
[Source URL](https://developer.apple.com/news/?id=dhwadr2x) (Apple Developer News)
